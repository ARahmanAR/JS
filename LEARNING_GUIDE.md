# JavaScript Journey - Learning Guide

## Getting Started

This repository is structured to guide you through JavaScript fundamentals step by step. Each topic builds on the previous ones.

## Prerequisites

- Node.js installed on your computer (version 12 or higher)
- A code editor (VS Code, Sublime Text, or any text editor)
- Basic understanding of programming concepts (helpful but not required)

## Quick Start

```bash
# Clone this repository
git clone https://github.com/ARahmanAR/JS.git
cd JS

# Run the main overview
npm start

# Or run individual topics
npm run basics
npm run variables
npm run functions
npm run arrays
npm run objects
npm run control-flow
npm run loops
```

## Learning Path

### Week 1: Foundations
**Days 1-2: Basics**
- Run `node basics/01-hello-world.js`
- Run `node basics/02-data-types.js`
- Experiment with different data types
- Try creating your own variables

**Days 3-4: Variables**
- Run `node variables/01-declarations.js`
- Understand the difference between var, let, and const
- Practice with block scope
- Create your own examples

**Days 5-7: Functions**
- Run `node functions/01-basics.js`
- Write your own functions
- Try arrow functions
- Experiment with parameters

### Week 2: Data Structures
**Days 8-10: Arrays**
- Run `node arrays/01-basics.js`
- Practice array methods
- Create arrays and manipulate them
- Try map, filter, and reduce

**Days 11-14: Objects**
- Run `node objects/01-basics.js`
- Create your own objects
- Practice with object methods
- Use destructuring

### Week 3: Control Flow
**Days 15-17: Conditionals**
- Run `node control-flow/01-conditionals.js`
- Practice if/else statements
- Use switch statements
- Try ternary operators

**Days 18-21: Loops**
- Run `node loops/01-basics.js`
- Master different loop types
- Practice with break and continue
- Create nested loops

### Week 4: Practice & Projects
**Days 22-28: Apply Your Knowledge**
- Combine concepts to build small programs
- Create a calculator
- Build a todo list
- Make a simple game

## Tips for Success

1. **Practice Daily**: Code every day, even if just for 15 minutes
2. **Type, Don't Copy**: Type out the code yourself to build muscle memory
3. **Experiment**: Modify the examples to see what happens
4. **Build Projects**: Apply what you learn to real projects
5. **Ask Questions**: Use comments to document what you don't understand
6. **Review**: Go back and review previous topics regularly

## Common Exercises

### Exercise 1: Calculator
Create a calculator that can add, subtract, multiply, and divide.

### Exercise 2: Array Manipulation
Create a program that:
- Creates an array of numbers
- Filters even numbers
- Doubles each number
- Sums the results

### Exercise 3: Object Practice
Create an object representing a person with:
- Name, age, hobbies (array)
- A method to introduce themselves
- A method to add a new hobby

### Exercise 4: Loop Practice
Write a program that:
- Prints numbers 1-100
- For multiples of 3, print "Fizz"
- For multiples of 5, print "Buzz"
- For multiples of both, print "FizzBuzz"
