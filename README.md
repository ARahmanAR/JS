# JavaScript Course

A comprehensive JavaScript learning journey covering fundamentals to advanced concepts with practical examples and projects.

## 📚 Course Structure

### 01-Basics
Learn the fundamental concepts of JavaScript:
- **Variables & Data Types** - Understanding let, const, var, and primitive types
- **Operators** - Arithmetic, comparison, logical, and advanced operators
- **Control Flow** - if-else, switch, loops, and error handling

### 02-Intermediate
Master intermediate JavaScript concepts:
- **Functions** - Function declarations, expressions, arrow functions, closures
- **Arrays** - Array methods, iteration, transformation, and manipulation
- **Objects** - Object creation, methods, destructuring, and patterns

### 03-Advanced
Explore advanced JavaScript features:
- **Async/Await** - Promises, async patterns, and asynchronous programming
- **ES6+ Features** - Modern JavaScript syntax and capabilities

### 04-Projects
Apply your knowledge with practical projects:
- **To-Do List** - Full-featured task management application
- **Calculator** - Advanced calculator with history and operations

### 05-Exercises
Practice with hands-on exercises:
- **Beginner Exercises** - 15 fundamental programming challenges
- **Intermediate Exercises** - Advanced patterns and utilities

## 🚀 Getting Started

1. Clone this repository
2. Start with `01-Basics` folder
3. Run each file with Node.js:
   ```bash
   node 01-Basics/01-variables.js
   ```
4. Progress through each section in order
5. Complete the exercises to reinforce learning

## 📖 Learning Path

**Week 1-2: Basics**
- Master variables, data types, and operators
- Understand control flow and loops
- Practice with basic exercises

**Week 3-4: Intermediate**
- Deep dive into functions and closures
- Master array and object manipulation
- Build your first mini-project

**Week 5-6: Advanced**
- Learn asynchronous JavaScript
- Explore ES6+ modern features
- Complete advanced exercises

**Week 7-8: Projects**
- Build real-world applications
- Apply all learned concepts
- Create your own projects

## 💡 Tips for Success

- **Practice Daily**: Code every day, even if just for 30 minutes
- **Build Projects**: Apply concepts by building real applications
- **Debug Actively**: Use console.log and browser dev tools
- **Read Documentation**: Refer to [MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
- **Join Communities**: Engage with other learners on forums and Discord
