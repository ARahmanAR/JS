# JavaScript Journey 🚀

Welcome to your JavaScript learning journey! This repository contains structured examples and exercises to help you master JavaScript fundamentals.

## 📚 Topics Covered

### 1. **Basics**
- Hello World
- Data Types (String, Number, Boolean, Undefined, Null)
- Type checking with `typeof`

### 2. **Variables**
- Variable declarations (`var`, `let`, `const`)
- Block scope vs Function scope
- Best practices for variable usage

### 3. **Functions**
- Function declarations
- Function expressions
- Arrow functions
- Default parameters
- Rest parameters

### 4. **Arrays**
- Creating and accessing arrays
- Array methods (`push`, `pop`, `shift`, `unshift`)
- Iteration methods (`forEach`, `map`, `filter`, `find`)
- Array utilities

### 5. **Objects**
- Creating objects
- Accessing and modifying properties
- Object methods
- Using `this` keyword
- Object destructuring
- Spread operator

### 6. **Control Flow**
- if/else statements
- Ternary operator
- Switch statements
- Logical operators
- Nullish coalescing

### 7. **Loops**
- for loop
- while loop
- do-while loop
- for...of loop
- for...in loop
- break and continue

## 🚀 Getting Started

1. Clone this repository
2. Navigate to the project directory
3. Run the main file:
   ```bash
   node index.js
   ```

## 📖 How to Use This Repository

Each topic has its own directory with numbered examples. Start with `basics` and work your way through:

1. **basics/** - Start here to understand fundamental concepts
2. **variables/** - Learn about variable declarations and scope
3. **functions/** - Master different types of functions
4. **arrays/** - Work with collections of data
5. **objects/** - Understand object-oriented concepts
6. **control-flow/** - Learn conditional logic
7. **loops/** - Master iteration techniques

### Running Individual Examples

Navigate to any directory and run the examples:

```bash
# Run the hello world example
node basics/01-hello-world.js

# Run data types example
node basics/02-data-types.js

# Run functions example
node functions/01-basics.js
```
